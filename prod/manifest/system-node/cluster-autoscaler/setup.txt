Cluster Autoscaler 설치
======================================================================
(이 디렉토리에서 실행)

// 배포 (네임스페이스는 kube-system, 이미 있으므로 생성 불필요)
1. kubectl apply -f .

// 기동 대기
2. kubectl -n kube-system rollout status deploy/cluster-autoscaler

// ASG 인식됐는지 확인
3. kubectl -n kube-system logs deploy/cluster-autoscaler | grep -i "node group"


사전 조건 (terraform 쪽, 이미 되어 있음)
----------------------------------------------------------------------
IAM   iam/main.tf:66-91    SetDesiredCapacity / TerminateInstanceInAutoScalingGroup
                           조건: ResourceTag k8s.io/cluster-autoscaler/cardinal-prod
ASG   app-asg/main.tf:21   k8s.io/cluster-autoscaler/enabled       = true
                           k8s.io/cluster-autoscaler/cardinal-prod = owned
노드  각 user_data          --provider-id=aws:///$AZ/$INSTANCE_ID


버전
----------------------------------------------------------------------
클러스터 1.34.9  →  cluster-autoscaler v1.34.5
CA는 스케줄러 로직을 그대로 쓰므로 마이너 버전을 반드시 맞출 것


동작 범위
----------------------------------------------------------------------
대상    app ASG 만 (태그로 자동 발견, ASG 이름 하드코딩 안 함)
범위    min 1 / max 3  ← terraform main.tf 의 app_asg 설정이 상한
        CA는 이 범위를 넘지 못한다. 더 필요하면 max_size 부터 올릴 것
제외    CP(테인트), system 노드(ASG 아닌 고정 EC2) → CA가 못 건드림

스케일아웃  파드가 Pending → 노드 추가로 뜰 수 있는지 계산 → SetDesiredCapacity
스케일인    10분 이상 놀고 있고 파드를 다른 노드로 옮길 수 있으면 종료
            DaemonSet(node-exporter) 파드는 판단에서 제외됨


주요 인자
----------------------------------------------------------------------
--node-group-auto-discovery   ASG를 이름이 아니라 태그로 찾음
                              (name_prefix 라 ASG 이름에 랜덤 접미사가 붙음)
--expander=least-waste        여러 후보 중 남는 자원이 가장 적은 쪽 선택
--skip-nodes-with-local-storage=false
                              emptyDir/hostPath 쓰는 파드가 있어도 축소 허용
                              app 노드는 무상태라 켜둠. 데이터 유실 주의
--scale-down-unneeded-time    10분 (기본값)
--v=4                         판단 근거가 로그에 남음. 안정화되면 2로 낮춰도 됨


확인
----------------------------------------------------------------------
kubectl -n kube-system get pods -l app=cluster-autoscaler -o wide
  → system 노드에 떠 있어야 함

kubectl -n kube-system get cm cluster-autoscaler-status -o yaml
  → 인식한 노드 그룹과 현재/목표 노드 수

실동작 테스트 (파드를 일부러 Pending 만들기):
  kubectl create deploy hog --image=nginx --replicas=10
  kubectl set resources deploy hog --requests=cpu=800m
  kubectl get nodes -w          → 몇 분 뒤 노드 증가
  kubectl delete deploy hog     → 10분 뒤 축소


문제 생기면
----------------------------------------------------------------------
kubectl -n kube-system logs deploy/cluster-autoscaler --tail=50

"Failed to regenerate ASG cache"      → IAM 권한 또는 AWS_REGION 확인
"Unable to find any node groups"      → ASG 태그 확인
"no expandable node groups"           → 이미 max_size 도달
파드가 계속 Pending인데 반응 없음      → 요청 자원이 인스턴스 타입보다 큰 경우
