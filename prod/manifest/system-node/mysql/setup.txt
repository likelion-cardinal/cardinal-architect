MySQL 설치 (단일 인스턴스, hostPath on EBS)
======================================================================
(이 디렉토리에서 실행)

// 네임스페이스 생성
1. kubectl create namespace database

// 비밀번호 설정 (root + 애플리케이션 계정 cardinal)
2. kubectl -n database create secret generic mysql-secret \
     --from-literal=root-password=<root 비밀번호> \
     --from-literal=password=<cardinal 계정 비밀번호>

// 배포
3. kubectl apply -f .

// 최초 기동 확인 (시스템 테이블 생성에 수 분 걸린다)
4. kubectl -n database rollout status deployment/mysql

// 접속 확인
5. kubectl -n database exec -it deploy/mysql -- \
     mysql -u cardinal -p cardinal


선행 조건 — terraform 데이터 EBS
----------------------------------------------------------------------
- terraform/main.tf 의 data_volume_size = 20 이 apply 되어 있어야 한다.
  이 값이 0이면 /mnt/data 가 루트 EBS 위에 생기고, AMI 교체로 노드가
  replacement 될 때 DB가 통째로 사라진다.
- 노드에서 확인: mountpoint -q /mnt/data && echo OK
  (user_data 가 마운트 실패 시 /var/log/cardinal-join.log 에 WARNING 을 남긴다)
- 같은 EBS 를 prometheus(/mnt/data/prometheus), grafana(/mnt/data/grafana)
  와 공유한다. Prometheus 는 5GB 상한이 걸려 있어 디스크를 잠식하지 않는다.


애플리케이션에서 접속
----------------------------------------------------------------------
- 호스트: mysql.database.svc.cluster.local  (포트 3306)
- ArgoCD 가 앱을 default 네임스페이스에 배포하므로 네임스페이스가 다르다.
  짧은 이름 "mysql" 로는 안 되고 위 FQDN 을 써야 한다.
- DB/계정 이름은 둘 다 cardinal (mysql.yaml 의 env 에 평문으로 있음)


주의사항
----------------------------------------------------------------------
- MYSQL_DATABASE / MYSQL_USER / 비밀번호는 데이터 디렉토리가 비어 있을 때
  최초 1회만 적용된다. 이미 데이터가 있으면 무시되므로, 나중에 비밀번호를
  바꾸려면 secret 이 아니라 MySQL 안에서 ALTER USER 로 바꿔야 한다.
- MySQL 8.4 는 caching_sha2_password 가 기본이다. 드라이버가 오래되면
  "Authentication plugin cannot be loaded" 가 난다. JDBC 는 mysql-connector-j
  8.x 이상, Python 은 PyMySQL 1.x 이상을 쓸 것.
- replicas 를 2 이상으로 올리면 안 된다. hostPath 를 공유하는 구조라
  복제가 아니라 데이터 파손이 된다. strategy: Recreate 도 같은 이유다.
- 백업은 이 매니페스트에 없다. mysqldump CronJob 을 별도로 두거나,
  최소한 축제 전후로 수동 덤프를 뜰 것:
    kubectl -n database exec deploy/mysql -- \
      sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" mysqldump -u root --all-databases' \
      > backup-$(date +%F).sql
- 노드가 1대뿐이라 이 파드가 죽으면 DB도 같이 내려간다(HA 없음). 데이터는
  EBS 에 남으므로 파드만 다시 뜨면 복구된다.
